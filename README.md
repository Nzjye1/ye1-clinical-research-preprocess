# Ye1 临床科研数据预处理

**在本地整理临床科研表格，生成保留研究信息的工作副本。**

面向支持 Skill 指引的各类 AI Agent，用自然语言交办任务。

## 能做什么

- 在用户电脑上处理本地 Excel 或 CSV，生成新的科研工作文件并保留原表。
- 按约定移除姓名、手机号和身份证号三类列，保留其他研究字段与日期时间。
- 保留已有患者编号；需要时按患者建立编号，方便多表和后续资料衔接。
- 处理多个工作表或文件，并在对应关系明确时让同一患者沿用同一编号。
- 向用户反馈处理结果、文件位置和必要的核对事项。

## 安装到你的 Agent

将下面这段话发给你的 Agent：

> 请从 https://github.com/Nzjye1/ye1-clinical-research-preprocess 获取 Ye1 临床科研数据预处理。读取 `skills/ye1-clinical-research-preprocess/SKILL.md`，按照当前 Agent 支持的方式安装完整 Skill 文件夹并检查所需工具，然后告诉我如何开始使用。

也可以下载 [通用 Skill 包](downloads/ye1-clinical-research-preprocess-skill.zip)，解压后将完整文件夹导入或放入所用 Agent 的技能目录；WorkBuddy 用户可使用 [WorkBuddy 导入包](downloads/ye1-clinical-research-preprocess-workbuddy.zip)。

数据处理使用数据所在电脑的本地工具，生成新工作文件并保留原始文件。

## 开始使用

你可以从当前最需要的环节开始，把下面适合你的一段话发给 Agent。

### 1. 处理一份临床科研表

> 我的电脑上有一份临床科研表，请在本地生成工作副本，去掉姓名、手机号和身份证号列，保留其他研究数据与完整日期时间。

### 2. 已有患者编号

> 这份表已经有患者 ID，请保留原有编号，处理指定身份信息列，并把结果另存为新文件。

### 3. 没有患者编号

> 这份表没有患者 ID，请在本地按患者建立编号后处理指定身份信息列；需要保留的对应关系也留在本机。

### 4. 处理多个工作表

> 这份 Excel 有多个工作表，请逐表处理指定身份信息列，保留其他列、工作表和日期时间。同一患者有明确对应关系时使用同一个编号。

### 5. 处理多份数据

> 我有几份需要一起使用的临床数据，请在本机分别生成工作副本，保留已有编号，并在对应关系明确时为同一患者沿用同一个编号。

### 6. 追加新收集的资料

> 我又收集了一批资料，请结合此前的原表或本机对应关系，给已经出现过的患者沿用原编号，新患者使用新编号；不确定的对应关系请标出来。

### 7. 核对处理结果

> 处理完成后请检查新文件是否保留了研究字段和日期时间，并告诉我文件位置和处理情况，不要在聊天中展示患者记录。

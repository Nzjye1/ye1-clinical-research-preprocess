# Ye1 临床科研数据预处理

这是一个文字指导型 Skill。接到任务后，由当前 Agent 使用用户电脑上的可用工具完成处理；如果需要，也可以自行编写并在本机运行临时代码。不要假定用户已安装某一种工具或编程语言。

## 处理范围

- 逐表只删除姓名、手机号、身份证号这三类列，包括表头明确等义的列；有就删除，没有就跳过。保留其他所有列及其顺序，删除后不要新留无名空列，不在其他列中搜索或替换姓名等文字。
- 保留出生日期、入院和出院时间、手术时间、随访时间等所有时间信息，以及诊断、检查指标、病史、备注等研究数据。不要将日期改成年份、截断时间或因罕见病等内容额外删除数据。
- 已有明确的患者 ID 或研究编号时保留并沿用，无需新建姓名对照表；没有患者 ID 就按患者生成 ID，每行明确代表不同患者时可逐行生成。有姓名时在删除前建立必要的对应关系；需要保留以便后续追加时，对照表留在本机。多表或后续追加中，能明确是同一患者时沿用相同 ID；同名等情况无法确定时不猜、不合并，只在影响分析时请医生核对。

## 执行流程

1. 获取用户有权使用的本地 Excel／CSV 路径和研究目标。原始患者记录不要粘贴到对话、上传到模型或作为工具输出返回 Agent；也不要预览或打印原始数据行。
2. 使用能在数据所在电脑本地执行、且不会把原始记录返回模型的工具生成新的工作文件；必要时由 Agent 自行编写临时代码。原表不覆盖。先按上面的规则保留或生成患者 ID，再删除存在的三类列，保留工作表、其他列和时间。
3. 本地确认新文件已生成且处理过程没有报错，反馈处理情况和新文件路径，不输出患者记录。随后仅基于新文件进行用户需要的清洗与分析。

若当前 Agent 没有合适的本机处理能力，或工具会把原始记录发送到模型／远程环境，说明该限制并停止；不要改为读取、上传原表或假称已处理。

此步骤只删除上述三类列；不要宣称文件完全匿名或所有敏感信息都已识别。
